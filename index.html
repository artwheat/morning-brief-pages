Morning Brief Automation

This is a personal automation script used by a single individual It is not a public product or service, has no other users, and is not distributed to third parties.

What it does

  • Reads a personal daily-planning file and writes a summary to a Google Doc in the owner's own Drive.
  • Reads a personal news-source reference file and mirrors it to a Google Doc in the owner's own Drive.
  • Reads and updates a rotating quote/affirmation list stored as a Google Doc in the owner's own Drive.

All data accessed and written stays within the app owner's own Google account. No data is shared with, sold to, or accessed by any third party.
