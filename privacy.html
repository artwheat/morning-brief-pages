Privacy Policy

Last updated: September 12, 2026

This application is a personal automation script written and used solely by its owner. It has no other users.

Data accessed

Google Drive files and Google Docs owned by the app owner's own Google account, via the Drive API (drive.file scope) and Docs API (documents scope).

How data is used

The app reads and writes only files it creates itself, or files explicitly designated by the owner within their own Drive, to automate personal note-taking and daily-planning tasks (e.g. writing a daily summary doc, mirroring a personal reference file, maintaining a rotating quote list).

Data sharing

No data is shared with, sold to, transmitted to, or made accessible to any third party. All data stays within the owner's own Google account.

Data retention

Data persists only in the owner's own Google Drive, under their own control, for as long as they choose to keep it. The app owner may delete any of this data at any time through Google Drive directly.

Contact

The app owner can be reached via the developer contact email on file in the associated Google Cloud project.
